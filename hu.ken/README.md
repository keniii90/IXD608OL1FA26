# Morning Brew Coffee

Morning Brew Coffee is a responsive e-commerce concept for freshly roasted coffee. This module develops the visual style guide and applies it to the landing page so the website and proposal use one consistent design system.

## Project Links

- [Live Website](https://www.ken-hu.com)
- [GitHub Repository](https://github.com/keniii90/IXD608OL1FA26)
- [Editable Proposal](docs/Morning_Brew_Coffee_Editable_Proposal.pptx)
- [PDF Proposal](docs/Morning_Brew_Coffee_Ecommerce_Proposal.pdf)
- [Website Style Guide](https://www.ken-hu.com/styleguide/)

## Style Guide Summary

- **Colors:** Espresso `#231A17`, Coffee `#4A2F24`, Latte `#D9B892`, Cream `#F3EADF`, Leaf `#50624B`, Ink `#292421`
- **Heading font:** Georgia, Times New Roman, serif
- **Body font:** Arial, Helvetica, sans-serif
- **Grid:** 12 columns on desktop, 8 columns on tablet and 4 columns on mobile
- **Maximum content width:** 1200px
- **Desktop gap:** 24px
- **Base spacing unit:** 8px

## Responsive Breakpoints

- Mobile: below `600px`
- Tablet: `600px` and above
- Desktop: `900px` and above

## Module Deliverables

- Interactive website style guide with a table of contents, typography, colors, sizing, spacing and component rules
- Reusable examples for cards, navigation variations, tables and figures
- Responsive landing page aligned with the proposal design
- Proposal files included in the repository
- README with links to the website, proposal and repository

## Publishing Checklist

1. Open `index.html` and `styleguide.html` locally and check both pages.
2. Create a GitHub repository and upload the complete project folder.
3. Commit with a message such as `Add website style guide and update README`.
4. Publish the repository using the required web host.
5. Confirm that the website and Style Guide links open correctly.
6. Commit and push the updated `README.md`.
7. Submit the GitHub repository link.
